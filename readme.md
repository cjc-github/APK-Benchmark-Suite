# APK Benchmark Suite

这是一个用于测试和分析Android APK文件的基准测试套件。

## 项目结构

```
APK-Benchmark-Suite/
├── benchmarks/           # APK文件和测试数据
│   ├── apk_list.md      # APK列表和分类信息
│   ├── *.apk            # APK测试文件
├── LICENSE              # 许可证
└── readme.md           # 项目说明
```

## 快速开始

1. 查看 `benchmarks/apk_list.md` 了解所有APK文件及其特性
2. 下载需要的APK文件到 `benchmarks/` 目录
3. 根据需要进行测试和分析
